# CatRescue-1 指令集

文本和语音使用同一套解析规则。中文、英文可以使用完整句，也可以使用下列短指令。

## 小车控制

| 指令示例 | 行为 |
|---|---|
| `向前` / `前进` / `forward` | 持续前进 |
| `后退` / `倒车` / `backward` | 持续后退 |
| `左转` / `右转` | 持续转向 |
| `停止` / `停下` / `停` / `stop` | 急停并取消当前自主任务 |
| `向前 200 cm` / `后退 1 米` | 定距移动 |
| `左转 90 度` / `turn right 45 degrees` | 定角转向 |
| `加速` / `快点` / `中速` / `减速` / `慢点` | 调整速度档位 |

## 导航与搜索

区域可以说 `A区` 到 `H区`，也可以说猫爬架、纸箱、窗台、书架、沙发、桌底、盆栽、茶水间。

| 指令示例 | 行为 |
|---|---|
| `去 C 区` / `go to zone C` | 只导航到 C 区 |
| `去茶水间` | 只导航到 H 区 |
| `找猫` / `find cat` | 探索各区域，寻找任意猫 |
| `找狗` / `find dog` | 探索各区域，寻找狗 |
| `找鸟` / `find bird` | 探索各区域，寻找鸟类 |
| `找动物` / `find animal` | 寻找猫、狗或鸟 |
| `去 B 区找布偶猫拍照喂食` | 导航、确认品种、执行动作 |
| `回去` / `回到起点` / `return` | 从当前位置返回起点 |

当前猫品种模型支持：`波斯猫`、`布偶猫`、`斯芬克斯猫`、`新加坡猫`、`兔狲`。也可不指定品种，直接说“找猫”。当前模型不支持暹罗猫、缅因猫和孟加拉猫，系统会明确拒绝这些指令，避免执行一个不可能成功的任务。

COCO 检测器只能确认 `bird`，所以“找鸡”会按“找鸟”执行，不能保证识别到的一定是鸡。

## 护理动作

护理动作需要和搜索目标一起说，例如：

| 触发词 | 动作 |
|---|---|
| `玩` / `逗` / `play` | 陪玩 |
| `喂` / `投喂` / `feed` | 投喂 |
| `拍照` / `photo` | 拍照 |
| `安抚` / `talk` | 声音安抚 |
| `照顾` / `互动` / `一条龙` | 组合动作 |

这些指令与任务状态机已经连通，但当前 [action.py](../src/action.py) 中的投喂器、逗猫器和扬声器驱动仍是硬件占位实现；它们会进入流程和日志，还不能代表真实硬件动作已经完成。

## 机械臂

| 中文指令 | 英文指令 | 键盘 | 行为 |
|---|---|---|---|
| `左转座` / `基座左转` | `turn base left` | Q | 基座向左移动一步 |
| `右转座` / `基座右转` | `turn base right` | E | 基座向右移动一步 |
| `放下机械臂` / `降臂` | `lower arm` | R | 大臂下降一步 |
| `抬起机械臂` / `抬臂` | `raise arm` | F | 大臂抬起一步 |
| `伸出机械臂` / `伸臂` | `extend arm` | T | 小臂伸出一步 |
| `收回机械臂` / `收臂` | `retract arm` | G | 小臂收回一步 |
| `切换夹爪` / `张开` / `抓` | `open gripper` / `close gripper` | Space | 切换夹爪开合状态 |
| `机械臂归位` / `归位` | `arm home` | Z | 所有舵机归位 |
| `机械臂演示` / `演示` | `arm demo` | P | 执行演示序列 |

当前树莓派协议对夹爪只有“切换”命令，没有独立的强制打开和强制闭合命令。因此 `打开夹爪` 与 `闭合夹爪` 都会切换一次，最终状态取决于树莓派记录的当前夹爪状态。

## 键盘

`W/A/S/D` 驾驶，`X` 急停，`1/2/3` 调速，`[/]` 调步长，`C` 拍照。机械臂使用 `Q/E/R/F/T/G/Space/Z/P`。输入框获得焦点时，键盘快捷键不会触发。
